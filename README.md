# Fantasy Premier League Ultimate

### Info

FPL Ultimate is a draft-style fantasy sports website based on the 
English Premier League.

### Variable Style Guide

* Manager - User (i.e. yourself)
* Player - A footballer belonging to a club in the Premier League  
* Team - Players selected by a manager
* Squad - Players selected by a manager to play in a specific gameweek
* League - A collection of users competing for a season
* Club - Real-life team that a player belongs to
